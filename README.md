# Cognito Study — 認証ハンズオン問題集

用意されたUIのTODOを埋めて、Cognitoによる新規登録、メール確認、ログイン、TOTPによるMFA、セッションの確認、サインアウトを実装します。Cognito認証の9つの課題をすべて実装し、[完了チェック](docs/exercises.md#完了チェック)を満たせば、この問題集は完了です。

認証処理は各ページのハンドラー内に直接書きます。共通の認証関数やエラー分類の実装は不要です。Contextはメールアドレスと`nextStep`を画面間で渡すために使います。Cognitoを呼び出すライブラリにはAmplify Authを使います。

課題の順番・場所・完了条件は[問題集](docs/exercises.md)にあります。

## 起動と接続設定

```bash
npm install
cp .env.example .env.local
npm run dev
```

開発サーバーを起動する前に、`.env.local`の次の2項目を設定してください。変更後は開発サーバーを再起動します。

```dotenv
NEXT_PUBLIC_COGNITO_USER_POOL_ID=<User Pool ID>
NEXT_PUBLIC_COGNITO_CLIENT_ID=<App Client ID>
```

Cognitoは次の設定を前提にします。

- メールアドレスでログインする。
- メールで届くコードで登録を確認する。
- 認証アプリ（TOTP）のみの必須MFAを使う。
- App Clientにクライアントシークレットを設定しない。

C01で接続設定を実装してから、Cognitoを使った認証処理へ進みます。

## 課題の進め方

対象ファイルの次のコメントを探し、コメント間の仮置きの`throw`を実際のコードに置き換えます。未実装のフォームはTODOメッセージを表示します。`/home`と`/mfa/setup`は、実装前に直接UIを確認できます。

```tsx
// [COGNITO Cxx START]
// TODO: ここにSDKの呼び出しと結果に応じた処理を書きます。
// [COGNITO Cxx END]
```

1. [問題集](docs/exercises.md)の順番に対象ファイルを開きます。最初はC01の接続設定から始めます。
2. コメントを読み、「どのSDKを呼ぶか」「何を渡すか」「結果を受け取って何をするか」を確認します。
3. コメントの下に実際のコードを書きます。必要なSDKのimportや、Pageの先頭での`useRouter()`の準備も行います。
4. SDKから返った`isSignedIn`や`nextStep`を使い、同じハンドラー内に条件分岐と画面遷移を書きます。コードが少し重複しても、そのページだけで流れを読めることを優先します。
5. 1つの課題を書いたらブラウザで動かし、各課題の確認項目を満たしてから次へ進みます。迷ったらホームの学習カードで参考コードと返り値の例を確認できます。

| 順番 | 課題 | 内容 |
| --- | --- | --- |
| 1 | C01 | Cognitoへの接続設定 |
| 2 | C04 | ユーザー登録 |
| 3 | C06 | メールコードの確認 |
| 4 | C07 | メールコードの再送 |
| 5 | C05 | ログインと次の認証ステップへの遷移 |
| 6 | C09 | TOTPのQRコード表示と初回設定 |
| 7 | C11 | グローバルサインアウト |
| 8 | C08 | 2回目以降のログインでのMFA |
| 9 | C10 | セッション確認とメールアドレス表示 |

登録確認はログインとは別の処理です。自動サインインは使わず、メール確認後にログイン画面へ進みます。初回設定のあとにサインアウトを実装し、2回目以降のMFA、最後にセッションからのメールアドレス表示へ進みます。

`nextStep`を画面間で渡すときはContextを使います。共有値は再読み込みすると消えるため、初回設定画面に値がない場合はログインからやり直す案内を表示してください。

## 完了条件

9つの課題を実装したうえで、次の2つの流れを確認します。

- 初回：新規登録 → メールコード確認 → ログイン → 認証アプリの初回設定 → ホームでメールアドレスを表示
- 2回目以降：サインアウト → ログイン → 登録済みの認証アプリのコード確認 → ホームでメールアドレスを表示

さらに、コードを間違えた場合のエラー表示、メールコードの再送、サインアウト後のセッション終了、未ログインでホームを開いた場合のログイン画面への遷移を確認します。エラーはSDKのメッセージをそのまま表示して構いません。

[問題集の完了チェック](docs/exercises.md#完了チェック)をすべて満たしたら、Cognito認証のハンズオンは終了です。追加の課題はありません。
